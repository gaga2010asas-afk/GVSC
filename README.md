# 🧠 Gaga Vibe Studio Code (GVSC)

**GVSC** — это AI-First среда разработки, созданная для геймдева. Она использует Python VIBE-скрипты и макросы для генерации кода, работы с файлами и интеграции нейросетей прямо в процесс создания игр (Godot, Unity и др.).

## ✨ Основные возможности
*   **VIBE-скрипты**: Генерация кода через Python-макросы (`app_create_file`, `app_replace_in_file` и др.).
*   **Интеграция с PAI Studio**: Прямое создание 3D-воксельной графики и текстур.
*   **Экономия памяти**: Оптимизация под системы с ограниченным объемом VRAM (от 6 ГБ).
*   **Умное управление контекстом**: Работа с большими проектами без переполнения контекста нейросети.

## 📥 Скачать и установить
Самый простой способ начать — скачать готовый установщик для Windows:
1. Перейдите в раздел **[Releases](https://github.com/gaga2010asas-afk/GVSC/releases)**.
2. Скачайте последний файл `GVSC_Setup_vX.X.X.exe`.
3. Запустите установщик и следуйте инструкциям.
